# Research — Spec 072

## Why requalification is required

Spec 067 closed the then-final native product, but Specs 068–071 subsequently changed brand/product structure, introduced first-class Models and Evidence routes, admitted a real portable local ONNX runtime behind Core authority, added Model Center operator workflows, and replaced comparative marketing-style verdicts with a fail-closed OpenMed claim ledger. Historical Spec 067 evidence therefore remains valid for its exact tree but is not sufficient by itself for the rebuilt product.

## Release truth

The release doctor remains intentionally not release-ready. Canonical Spec 059 identifies five release residual evidence classes that require external authority or measurement: macOS signed-product qualification, release SBOM signing provenance, qualified-hardware performance attainment, checksum/provenance signing verification, and final-v0 accessibility qualification. MESC is a separate project/repository and is excluded from the MedScale residual set, external-gate map, completion model, and execution scope.

## Accessibility truth

Repository tests can prove native roles, names, focus/default-action primitives, non-color-only status copy, and engineering contrast rules. They cannot prove VoiceOver/NVDA/Orca behavior, 200% rendered reflow, final rendered contrast/focus behavior, or WCAG conformance on the bound release package. The Spec 072 packet must therefore cover the rebuilt Models/Evidence surfaces while remaining an external action packet.

## Performance truth

The repository has launch, idle-RSS, delivery-plan-scale, and portable-package measurement paths. Final UI interaction latency remains `FINAL_UI_PRESENT_EXTERNAL_INTERACTION_MEASUREMENT_REQUIRED` on declared qualified hardware. Models/Evidence interactions must be added to the external measurement scope; hosted CI cannot set `budgets_claimed_met=true`.

## Authority boundaries

No real PHI, production credentials, online Hugging Face acquisition, OpenMed trusted-runtime import, work in the separate MESC project, or external gate bypass is authorized by this requalification.
