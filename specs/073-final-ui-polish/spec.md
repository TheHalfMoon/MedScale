# Spec 073 — Final UI Polish

Status: IN_PROGRESS

## Founder promotion

The founder explicitly requested: "finish up the UI". This fresh promotion reopens repository implementation for a bounded final native-UI polish pass only.

## Goal

Finish the MedScale native Desktop UI so it reads as a cohesive, production-grade local-first product while preserving every established authority, privacy, evidence, accessibility, and claim boundary.

## Acceptance criteria

1. Refine the shared visual system, navigation, top bar, page header, cards, actions, tabs, metrics, and status treatment without adding backend authority.
2. Finish the Home workspace hierarchy, AI inspection surface, clinical flow, and review queue with consistent spacing and interaction affordances.
3. Apply the shared polish across Patients, Insights, Models, Evidence, Workflows, governance, and utility routes through reusable components/tokens rather than one-off styling drift.
4. Preserve keyboard focus, accessible labels/actions, minimum window support, local-first status, evidence-first copy, release non-claims, and MESC project separation.
5. Capture rendered before/after evidence on the authorized macOS host.
6. Pass focused product/UI regressions, Desktop tests, formatting, Clippy, Rust 1.88, workspace qualification, exact-range review, exact-head required CI, protected merge, and post-main verification.

## Non-goals

No new clinical authority, provider integration, network authority, model claim, release-readiness claim, mobile implementation, MESC work, or backend feature is authorized by this spec.
