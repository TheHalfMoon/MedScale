# Quickstart — Spec 097 presentation preparation

From `apps/desktop-tauri`, use the existing locked dependency installation:

```text
rtk proxy npm test
rtk proxy npm run build
rtk proxy npm run dev
```

Open the loopback preview, select Patients, switch between Dark and Light, and
inspect 1440×900, 1100×720 and intermediate sizing. Enter on the availability
summary expands it; Ctrl+K opens route navigation and Escape restores focus.
Patient search is disabled and the count is unknown. No patient records appear.

Final evidence requires the exact-head native package produced by the existing
Tauri preview workflow, its inventory/receipt verification, and actual native
captures. Local Cargo execution remains blocked by the documented MSVC toolchain
gate. Browser frames do not close that native requirement.
