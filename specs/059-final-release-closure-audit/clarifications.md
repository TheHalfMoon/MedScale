- Historical evidence may preserve the state that was true when a prior spec closed. Only live/canonical current-state documents are synchronized.
- GitHub-hosted runners are not declared qualified performance hardware.
- macOS App Sandbox/product qualification remains external because signed entitlement enforcement, notarization identity, and the final product shell are not available.
- Final v0/WCAG remains blocked by the user-supplied final v0 artifact.
- `IMPLEMENTATION_COMPLETE_PENDING_EXTERNAL_GATES` is a project implementation status, not `RELEASE_READY`.
- MESC remains optional and is not part of completion or release blocking.
