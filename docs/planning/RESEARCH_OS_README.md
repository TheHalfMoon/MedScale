# MedScale Research OS Planning Packet

Start at [`RESEARCH_OS_PLAN_INDEX.md`](./RESEARCH_OS_PLAN_INDEX.md).

This directory contains the documentation-only planning packet for the proposed MedScale Research OS expansion: Projects/Artifact Graph, collaboration, MedAgent, Fleet/Compare, Privacy Gate, Governed Browse, AudioFlow, Analytics, Knowledge/Research Canvas, self-hosted Hub, governed Compute, Research Packs, institutional adapters, later federation, and whole-platform qualification.

The current candidate roadmap spans Specs 074-089, subject to live frontier reconciliation before promotion.

For implementation-grade constraints, reviewers should read the Master Implementation Contract, Repository Implementation Map, Spec Implementation Contracts, Decision Resolution Register, Verification Matrix, Implementer Instructions, and [`RESEARCH_OS_GAP_CLOSURE_REVIEW.md`](./RESEARCH_OS_GAP_CLOSURE_REVIEW.md).

The packet is planning-only. It does not promote a candidate spec, authorize implementation, authorize real PHI, or alter current canonical repository/release authority.
