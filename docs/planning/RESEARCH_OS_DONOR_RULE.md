# Research OS Donor Rule

Permission to use a donor repository expands the set of legally/contractually possible engineering choices; it does not determine the correct architecture.

For Buzz, VoiceStudio, and every other donor:

> MedScale owns the contract, trust boundary, product vocabulary, tests, and upgrade strategy. Donor code is replaceable implementation detail.

This rule prevents the Research OS from becoming coupled to the architecture of whichever donor happened to be most feature-rich at planning time.
