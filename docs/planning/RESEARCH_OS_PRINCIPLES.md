# MedScale Research OS Principles

1. **The project is the context.** Intelligence, analysis, audio and collaboration should attach to durable project work.
2. **The Core is the authority.** No model, agent, event stream, BI system or speech engine silently becomes truth.
3. **Local is the default, not a marketing adjective.** Offline useful paths must remain real and tested.
4. **Sharing is user-controlled.** Hub, workers, connectors and external providers are explicit boundaries.
5. **Evidence survives transformation.** Derived artifacts keep links to exact source revisions, spans, times and runs.
6. **Many engines, one contract.** Compete/replace runtimes behind MedScale-owned interfaces.
7. **Unknown is a valid result.** Never manufacture parity, confidence or completion.
8. **Agents participate under capability.** Identity does not imply authority.
9. **Audio is evidence.** Transcription is a revision, not the source itself.
10. **Scale changes infrastructure, not semantics.** Personal, Lab and Institution use the same authority/provenance model.
11. **Domain growth happens through Packs.** Keep Core small enough to trust.
12. **Copy less, learn more.** Adopt the minimum donor surface that wins on measured requirements.
