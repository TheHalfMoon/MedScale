# MedScale Research OS Scope Boundary

**Status:** Planning candidate.

## In scope for the future program

- project-centric research work;
- governed agents/models/tools;
- reproducible analytics;
- audio/voice intelligence;
- evidence and retrieval;
- collaboration and user-controlled sync;
- bounded local/institutional compute;
- extensible scientific domain Packs;
- institutional adapters;
- later cross-institution research/federation.

## Explicitly not implied by this plan

- autonomous diagnosis/treatment authority;
- unreviewed real-PHI external model use;
- mandatory cloud SaaS;
- automatic voice recording;
- covert capture or OS privacy bypass;
- agent ownership of clinical truth;
- free-form arbitrary code inside the trusted Desktop process;
- bundled Superset/OpenRAG/Buzz/VoiceStudio applications as required runtime stacks;
- immediate mobile implementation;
- immediate federation;
- claims of HIPAA/GDPR/PDPL or other regulatory compliance without separate legal/technical qualification;
- production readiness of any source merely because it appears in the source ledger.
