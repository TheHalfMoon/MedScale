# MedScale Voice and Copy

**Status:** CANONICAL_SPEC_073

MedScale speaks like a precise clinical-technical colleague: concise, calm, specific, evidence-linked, and explicit about uncertainty.

Prefer `evidence`, `source`, `provenance`, `review`, `admitted`, `not admitted`, `supported`, `unsupported`, `unresolved`, `reconcile`, `local`, `authority`, `proposal`, `qualified`, `unqualified`, and `unmeasured` when they are accurate.

Avoid promotional filler such as `revolutionary`, `magical`, `effortless`, `smarter healthcare`, `next-generation AI`, unsupported `best-in-class`, and `seamless` across a real boundary.

Good product copy names the state and safe next action:
- `Production inference not admitted.`
- `Review required before action.`
- `Source conflict unresolved.`
- `Evidence present; authority unchanged.`
- `Unknown delivery state. Reconcile before retry.`

Buttons should use verb + object: `Review evidence`, `Open patient`, `Inspect model`, `Reconcile status`, `Prepare action`.

CLI human output may use restrained MedScale headings, but machine JSON/error contracts and exit-code semantics remain unchanged.
