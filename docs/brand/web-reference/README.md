# MedScale Web Identity Reference

**Status: NON_PRODUCTION_REFERENCE**

This directory is a documentation-only Spec 073 reference for a possible future Web surface. It is not a production Web application, runtime, build target, deployable package, server, release artifact, or capability claim.

`reference.html` and `tokens.css` demonstrate the approved monochrome mark, Instrument Sans/Source Serif typography intent, light-first theme, calm dark reference, semantic Mist Blue/Sage/amber/red usage, and dual-dock composition.

No package manager, JavaScript framework, server, API client, build script, or CI gate is authorized here. The native Desktop implementation remains the real product implementation in this repository.
