# MedScale Brand System — Start Here

**Current visual authority:** Spec 093 — Brand Identity System V2

The founder-approved MedScale identity is the ScaleFold M + MedScale Spectrum with a token-governed light/dark product system. Spec 073 remains historical visual evidence and safety work but is no longer the active visual direction.

## V0 handoff

Start in this order:
1. `V0_INPUT_MANIFEST.md`
2. `V0_MASTER_PROMPT.md`
3. `V0_ACCEPTANCE_CHECKLIST.md`
4. `PAGE_BLUEPRINTS.md`
5. `COMPONENT_SYSTEM.md`
