# Design Acceptance — Spec 066 Candidate

The candidate applies the shape/critique/audit/polish/harden discipline to launch surfaces: advertised navigation is complete, demo copy is semantically honest, review-first language replaces authority-implying verbs, the command affordance matches actual behavior, and dense layouts have a native minimum-size floor.

This is product hardening acceptance only, not final accessibility/performance/release qualification.

- Primary text tokens on white / soft-purple surfaces are regression-checked at an engineering 4.5:1 contrast floor; status-pill text uses semantic dark text rather than accent-only color. This does not claim WCAG conformance.
