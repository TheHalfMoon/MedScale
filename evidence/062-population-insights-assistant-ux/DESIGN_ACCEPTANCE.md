# Design Acceptance — Spec 062 Candidate

The candidate follows `DESIGN.md` by implementing Population Insights as a native evidence-aware work surface rather than fake analytics or a chatbot-first shell.

Acceptance points:
- population metrics are derived from deterministic synthetic trusted projections;
- coverage statuses remain distinct and visible;
- present-condition distribution excludes unresolved condition facts;
- cohort rows expose evidence state and review attention in text, not color alone;
- assistant suggestions are visibly bounded evidence context;
- evidence cards retain corpus/lifecycle/freshness/conflict metadata;
- risk/trend visuals become explicit non-claims rather than fabricated clinical analytics;
- tabs, assistant input, and quick actions use native keyboard/accessibility semantics inherited from the existing Slint system.

This is implementation/design acceptance only. It is not WCAG conformance, assistive-technology qualification, clinical risk qualification, or release readiness.
