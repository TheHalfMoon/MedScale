# CLI Design Acceptance — Spec 065 Candidate

The command tree follows the founder-approved product direction while remaining terminal-native: compact `status`, explicit `capabilities`, grouped noun-oriented read paths (`patient`, `actions`, `audit`, `fhir`), legacy compatibility, structured `--json`, concise text summaries, and discoverable help.

The UX deliberately favors authority clarity over pretending that a terminal should reproduce Desktop visual composition. This is CLI product/design acceptance only, not release or accessibility conformance.
