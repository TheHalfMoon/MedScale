# Spec 065 Candidate Limitations

- Current product scope remains synthetic/permitted development data; real PHI stdout is not authorized.
- Transient CLI sessions do not imply a shared long-running vault; Host IPC is the explicit persistent-host operator path.
- Outbox and disclosure product commands are read-only in this slice.
- Population Insights risk/trend and Workflow Studio layout do not gain a duplicate CLI authority.
- FHIR support output is not a CapabilityStatement or full-conformance claim.
- External signing, qualified-hardware performance, WCAG/assistive-technology qualification, and release readiness remain separate gates.
