## Explicit non-capabilities (verified by construction + review)

No capability exists for: triggering a clinical/external effect from a
collaboration approval, cross-project visibility, agent self-escalation to
human trust, silent last-write-wins on any mutable row, Hub network sync
execution, or free-form scripted formatting/markup execution on
message/note bodies (`security.md` section 3). Exact-range review
(`EXACT_RANGE_REVIEW.md`, performed with OpenCodeReview per explicit
instruction) records the full changed-file set and any additional findings.
